### What is this?

Taktik Robot is a focused set of tools for preparing textbook content, layouts and visual materials.

### How does it work?

Choose a tool from the left. Each drawer explains its output, local processing, and external services. AI requests pass through Robot's server to OpenRouter and the selected provider; shared usage logging attaches a pseudonymous user identifier and records usage/cost metadata. Local document processing does not upload the source document, but may download browser runtimes, libraries, or language data. Local storage is specific to this browser and can be lost when site data is cleared.
