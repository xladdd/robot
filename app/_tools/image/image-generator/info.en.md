### What is this?

Queue up to 15 prompts, typed or imported locally from DOCX, Markdown, or TXT, with up to three optional image references. Generate square images, retry individual results, or generatively upscale one size step to 1K or 2K. Style presets can add a style prompt and pin a seed.

### How does it work?

Only prompt text and supplied reference images are sent through Robot to OpenRouter; the imported document stays local. Fast and Fidelity use separate models. Upscaling sends the selected image for generative recreation, not pixel-identical enlargement. A fixed seed can improve repeatability but does not guarantee identical output across providers, models, or versions.

Transparent background is a best-effort local removal of light background connected to the image border, not general AI segmentation. Review edges and light subjects. ZIP downloads include transparent versions only for successful cutouts, alongside originals.

### Advanced mode

Advanced is currently disabled. When enabled, it builds a structured JSON prompt and offers a live FLUX model catalogue. Empty fields are omitted. Displayed prices are estimates; remaining credit and monthly-cap displays are not a guarantee of final price or request availability.
