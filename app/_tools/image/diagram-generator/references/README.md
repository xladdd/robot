# Reviewed composition references

This catalogue is deliberately small. It is a list of approved **composition references**, not a bulk icon library and not a licence to publish the placeholder entries.

Before adding an artwork:

1. Obtain the original file or a stable source URL from the rights holder or a licence that permits this workflow.
2. Record the exact source, licence, attribution requirements, reviewer, review date, and known biological limitations in `catalog.json`.
3. Put the local, approved asset beside the catalogue only after the licence is recorded. Set `assetPath` to the app-relative path.
4. Ask a biology editor and a production designer to review the silhouette, view, label capacity, and whether the artwork has complete underlying shapes rather than occlusion holes.
5. Keep source notes with the asset. Do not treat Bioicons, Wikimedia, or another aggregation as a single style or licence; verify each item individually.

The runtime currently uses user-uploaded references and the catalogue metadata. Entries with `assetPath: null` are planning hints only and are intentionally not downloaded or sent to OpenRouter.
