### What is this?

A prepared catalogue interface for Adobe scripts, currently disabled in the sidebar. It contains three InDesign scripts; broader InDesign, Illustrator, and Photoshop filters are prepared but do not imply that scripts for every application are available.

### How does it work?

The catalogue and downloads are bundled with Robot. Per-card download-click counts are stored in this browser's localStorage, not verified installation or successful-run counts. The module does not send those counts to a server.
