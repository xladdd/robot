### What is this?

Add up to six reference images that share a visual style and a test prompt for a subject. A Mistral vision planner studies the references and writes one reusable **FLUX.2 Pro style prompt** plus a style name and ID. The style prompt is then tested: three square images of your test prompt are generated with `black-forest-labs/flux.2-pro 🇩🇪`, each with a different random seed. Select the best of the three to pin its seed, refine the style prompt in the chat — with or without the selected image as guidance — and repeat the rounds until the style is right. **Finish Style** then shows the final prompt and pinned seed, and **Send style request** files an Asana task asking for the style to be added to the Image Generator's Default and Advanced modes, with a ready-to-paste preset entry.

### How does it work?

Reference images are prepared in the browser and sent only to the Mistral planner (`mistralai/mistral-medium-3-5` with a `mistralai/ministral-14b-2512` fallback) through OpenRouter. The planner returns structured JSON that the server validates before use. Test generations deliberately do **not** use the references: the finished style ships to the Image Generator as a prompt plus a pinned seed alone, so every round must reproduce the style without them — the same way the storybook presets pin seed 8701. The style prompt stays editable during testing; manual edits are kept when you revise. The Asana request contains only the style name, ID, prompt, pinned seed, test prompt, round count, and your optional note — never the reference or generated images.
